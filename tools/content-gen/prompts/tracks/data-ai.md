트랙: DATA_AI (데이터·머신러닝 — 분석 · 모델링 · ML 시스템)

이 트랙의 문항은 아래 실제 개념을 구체적으로 묻는다. 각 문항은 하나의 개념을 명확히 겨냥한다.
**웹 백엔드(Django·FastAPI 라우팅·ORM·인증)는 이 트랙이 아니다**(PYTHON_BACKEND 트랙 소관).
**컨테이너·쿠버네티스·CI 파이프라인 자체도 이 트랙이 아니다**(DEVOPS 트랙 소관). 배포를 묻더라도
**모델 서빙·재현성 관점**으로만 묻는다.
코드는 Python(pandas·numpy·scikit-learn·PyTorch)과 SQL 을 쓴다.

## 핵심 개념 목록

- **데이터 조작**: pandas 인덱싱(`loc` 대 `iloc`), 뷰 대 복사와 `SettingWithCopyWarning`, 결측치 처리,
  `merge` 의 조인 종류와 키 중복이 만드는 행 폭증, `groupby`-`agg`-`transform` 의 차이, 넓은 형식과 긴 형식,
  범주형 dtype, 시계열 리샘플링.
- **numpy**: 브로드캐스팅 규칙, 축(axis) 의미, 벡터화와 파이썬 루프의 차이, dtype 과 정밀도,
  뷰와 복사, 난수 시드.
- **SQL 분석**: 윈도 함수(`ROW_NUMBER`·`RANK`·누적합), `GROUP BY` 와 `HAVING`, 조인으로 인한 중복 집계,
  `NULL` 의 비교·집계 동작, CTE, 실행 계획과 인덱스.
- **통계 기초**: 표본과 모집단, 분산·표준편차, 상관과 인과, 심슨의 역설, 신뢰구간, p-값의 의미와 오해,
  A/B 테스트 설계(표본 크기·다중비교), 이상치 처리.
- **지도학습**: 학습·검증·테스트 분할, 교차검증, **데이터 누수(leakage)**, 과적합과 정규화,
  편향-분산, 특성 스케일링을 언제 학습 데이터에만 맞춰야 하는가, 범주형 인코딩.
- **평가 지표**: 정확도가 불균형 데이터에서 무의미한 이유, 정밀도·재현율·F1, ROC-AUC 대 PR-AUC,
  임계값 선택, 회귀의 MAE·RMSE·R², 지표를 비즈니스 목표에 맞추기.
- **비지도·차원축소**: k-means 와 초기화·k 선택, 계층 군집, PCA 가 하는 일과 스케일 의존성, 임베딩과 유사도.
- **딥러닝 기초**: 경사하강과 학습률, 배치 크기, 손실 함수 선택, 활성함수, 과적합 방지(드롭아웃·조기종료),
  전이학습, 기울기 소실.
- **LLM·임베딩**: 토큰화, 컨텍스트 창, 임베딩 벡터와 코사인 유사도, 벡터 검색과 RAG 의 구성 요소,
  프롬프트와 파인튜닝의 트레이드오프, 환각과 근거 제시.
- **ML 시스템·재현성**: 학습·서빙 간 특성 불일치(training-serving skew), 특성 저장소, 데이터·모델 버전 관리,
  실험 추적, 배치 추론과 실시간 추론, 모델 드리프트 감시, 시드 고정과 재현 가능한 파이프라인.
- **데이터 파이프라인**: 배치와 스트리밍, 멱등한 적재, 스키마 변경 대응, 파티셔닝, 데이터 품질 검사.

## CODE_READING 지침

짧은 Python 스니펫(5~15줄, pandas·numpy·scikit-learn) 또는 SQL 을 `content` 에 `\n` 으로 넣고,
**위 개념의 미묘한 동작·버그**를 읽어내게 한다.

겨냥할 만한 것: `loc` 슬라이스가 끝을 포함하는 것 · 체이닝 인덱싱으로 원본이 안 바뀌는 것 ·
`merge` 키 중복으로 행이 늘어나는 것 · 브로드캐스팅이 의도치 않게 성립하는 축 ·
**스케일러를 분할 전에 fit 해 누수가 생기는 코드** · 시계열을 무작위 분할하는 것 ·
불균형 데이터에서 정확도만 보는 평가 · `groupby` 후 `transform` 과 `agg` 의 결과 형태 차이 ·
`NULL` 이 섞인 집계 · 윈도 함수의 프레임 기본값.

`content` 는 코드만 두지 말고 **한국어 질문 문장을 함께** 넣는다.
